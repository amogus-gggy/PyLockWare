# Changelog - Поддержка строк в CustomVM

## Дата: 2025

## Основные изменения

### 1. Добавлена полная поддержка строк

#### Новые опкоды (opcodes.py)
- `INST_STR_LOAD (0x3A)` - загрузка строки из string pool
- `INST_STR_CMP (0x3B)` - сравнение строк (устанавливает флаги z/n/c)
- `INST_STR_CONCAT (0x3C)` - конкатенация строк
- `INST_STR_LEN (0x3D)` - получение длины строки
- `INST_STR_GET (0x3E)` - получение символа по индексу
- `INST_STR_SLICE (0x3F)` - срез строки [start:end]

#### Изменения в компиляторе (compiler.py)
- Добавлена поддержка строковых литералов `"text"`
- Отслеживание строковых переменных для правильной генерации операций
- Автоматический выбор между `STR_CONCAT` и `ADD` для оператора `+`
- Автоматический выбор между `STR_CMP` и `CMP` для операций сравнения
- Поддержка индексации строк: `s[i]` (константный и переменный индекс)
- Поддержка срезов строк: `s[start:end]`, `s[:end]`, `s[start:]`, `s[:]`
- Поддержка `len()` для строк
- Поддержка строк в булевом контексте (if/while)
- Поддержка augmented assignment для строк: `s += "text"`

#### Изменения в VM (vm.py)
- Расширен стек для поддержки смешанных типов (int и str)
- Добавлен `string_pool` для хранения строковых литералов
- Реализованы все строковые операции
- Добавлена функция `_to_comparable()` для корректного сравнения строк с числами
- Исправлена операция `ADD` для поддержки конкатенации строк
- Строки преобразуются в булевы значения: пустая строка = 0, непустая = 1

#### Изменения в builder (builder.py)
- Добавлен `string_pool` для хранения строк
- Добавлен метод `add_string()` для добавления строк в пул
- Добавлены методы для генерации строковых операций:
  - `str_load(idx)` - загрузка строки
  - `str_cmp()` - сравнение строк
  - `str_concat()` - конкатенация
  - `str_len()` - длина
  - `str_get()` - индексация
  - `str_slice()` - срез
- Секция 0x05 для сериализации string pool в .cvm файл

#### Изменения в loader (loader.py)
- Добавлена загрузка секции 0x05 (string pool)
- Исправлена индексация блоков шифрования для корректной работы с несколькими секциями
- Добавлена карта `section_block_map` для правильного соответствия секций и блоков шифрования

## Совместимость

Все изменения обратно совместимы. Существующий код продолжает работать без изменений.

## Производительность

- Строки хранятся в отдельном пуле, что экономит память
- Строковые операции выполняются нативно через Python, что обеспечивает высокую производительность
- Увеличение количества регистров не влияет на производительность существующего кода

## Известные ограничения

- Отрицательные индексы (например, `s[-1]`) не поддерживаются
- Срезы с шагом (например, `s[::2]`) не поддерживаются
- Методы строк (например, `s.upper()`, `s.split()`) не поддерживаются
- Форматирование строк (f-strings, format()) не поддерживается

## Примеры использования

```python
# Строковые литералы
greeting = "Hello"
name = "World"

# Конкатенация
message = greeting + ", " + name + "!"  # "Hello, World!"

# Длина
length = len(message)  # 13

# Индексация
first = message[0]  # "H"
i = 7
char = message[i]  # "W"

# Срезы
hello = message[:5]      # "Hello"
world = message[7:12]    # "World"
full = message[:]        # "Hello, World!"

# Сравнение
print(greeting == "Hello")  # 1
print(greeting < name)      # 1

# В условиях
if greeting:
    print("Not empty")  # выполнится

# Augmented assignment
result = "Start"
result += " End"  # "Start End"
```
